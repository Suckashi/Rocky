# Rocky visual source

Original editable SVG authored for this repository. The central faceted form has five broad articulated limbs, amber seams, and no eyes or mouth. Avatar is for 32–96 px; the simpler mark is preferred at 16–24 px. Both remain static until the separate T-038 presence implementation supplies confirmed state.

No external image, font, movie still, upstream avatar or raster texture is embedded. Local fragment references are used only to reuse the five limb geometries. The original source is Apache-2.0; that code license does not settle name, character inspiration or trademark rights. Distribution rights review remains pending in the manifest. This is a reviewable design baseline, not user-approved final artwork.

Product inspiration and constraints come from specs/rocky/ROCKY_BOT_DESIGN_SPEC.md. No original-film dialogue is used. The manifest SHA-256 values are checked in tests. assets/rocky is served locally through Vite's public directory and copied to the production web build.
