# Rocky visual source

This directory contains the editable Rocky product marks and favicon authored for this repository. The simpler mark is intended for small product identifiers. The previous `avatar.svg` was replaced by the Roko mascot; its atlas, animation manifest, and separate rights record live in [assets/roko](../roko/README.md). Product marks remain static, while Roko Presence follows daemon-confirmed activity.

No external image, font, movie still, upstream avatar or raster texture is embedded in these SVG files. Their source is Apache-2.0; that license does not settle name, character inspiration or trademark rights. Distribution rights review remains pending in the manifest.

Product inspiration and constraints come from specs/rocky/ROCKY_BOT_DESIGN_SPEC.md. No original-film dialogue is used. The manifest SHA-256 values are checked in tests. assets/rocky is served locally through Vite's public directory and copied to the production web build.
