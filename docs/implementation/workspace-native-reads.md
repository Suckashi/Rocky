# Native workspace reads with explicit Work scope

2026-10-04, Windows x64, Node24.12.0/npm11.6.4. Source `fcca9adee85b1b3cdb2a61e2d45e2e9e7ee9592e`. T-017/T-008/T-019 remain in_progress; no full acceptance or release claim.

Configured Work now binds an existing workspace id and exact revision. Registration alone grants no assistant access. The OpenDots-derived workspace dialog selects a root; the composer popover offers a default-off read scope for that Work and its ephemeral children. Sending resets the checkbox for the next Work. Model parameters, a frontend approved flag or a late unrelated grant cannot enlarge this scope. The daemon computes the grant target from registered root identity/revision and policy, committing Work, model budget and grant in one SQLite transaction. Submission replay never regrants revoked permission.

`workspace_info`, `workspace_files` and `workspace_read` use the existing daemon policy/operation ledger and worker RPC. Root and ephemeral children share owned Work scope; no additional runtime, scheduler, upstream backend or host filesystem backend. The model supplies only relative paths. Active grant checks precede receipt delivery/replay and follow asynchronous filesystem access; model revision is rechecked before delivery. Canonical/private-file/root identity boundaries apply. Metadata omits absolute host root. Content is untrusted evidence and uses existing credential redactors.

Read pages contain `path`, original `sha256`/byte size, `text`, Unicode-character `offset`, `nextOffset`, `totalCharacters` and `truncated`. Default page16384 characters, max65536; file cap1MiB. Nonzero offset requires original `expectedHash`; changed files fail instead of mixing revisions. Unicode code points are preserved. Pages bound escaped JSON/tool RPC size; native context offload remains virtual graph state. Directory listing remains200 returned/2000 scanned entries with explicit truncation.

Read failure is `failed_known_no_effect`. Stop/restart settles interrupted daemon-owned workspace reads and releases their claims. Dispatched external MCP operations remain unknown until confirmed. Read claims are per owned call to permit concurrent ephemeral readers; full shared-read/exclusive-write locks and worktree coordination remain future work.

Workspace revision and requested read scope are immutable. Checkpoint continuation, history and background inbox require matching id/revision/read scope. Switching revision or disabling reads excludes prior scoped model context. Retry without new read scope omits scoped answers/read payloads and never silently inherits grants. Owner-visible history remains. Retry regrant UI and complete context-reference governance are unfinished.

The paged test exposed fixed LangGraph recursionLimit30, failing after four ordinary reads. Worker start now gets daemon-derived `64 + 16 × maxCalls` graph steps (default832, max160064), bounded headroom for native middleware. Daemon model/token/cost/wall budgets retain their original authority. One native runtime remains; public worker errors stay generic. Temporary fixture debugging was removed before commit.
