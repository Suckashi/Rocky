# Native conversation compaction

T-011 / AT-21 contribution, Windows fixture. This uses Deep Agents1.14.1's public createSummarizationMiddleware and official SqliteSaver, not a second summarizer runtime or SDK patch.

The configured connection's input profile (context window minus output allowance) is passed by the daemon to the owned worker. WorkerModel exposes it through the public profile getter. The native middleware uses profile-relative trigger/retention defaults. Rocky replaces the same-name default middleware through the SDK's supported merge-by-name mechanism and supplies a prompt preserving goals, exact corrections, todos, sources and uncertain outcomes. It does not implement a separate cutoff planner or custom checkpoint format.

The installed SDK performs summaries through the active request model's unbound invoke. Its explicit summary-model option does not override that request model in this code path. Rocky's public bindTools implementation marks target calls with a trusted call option; unbound native calls use summary purpose. Purpose does not depend on user text. The worker transmits that purpose with its existing run capability and sequence. Daemon summary calls use the same model selection, shared slots and root budget, with no reply-stream projection. Empty summaries or summary tool calls fail before replacing context. Provider-private reasoning is still excluded by the existing decoder.

Cross-Work copying includes native messages/files, todos and the native summarization event/session metadata through public updateState. The cutoff refers to the copied full message list; retaining it avoids losing already-saved summary context or repeatedly summarizing all raw history after each new Work. Pending graph tasks, interrupts, grants and operation effects are not copied. A summary never grants authorization or proves Work/effect success.

Tests use actual native middleware/checkpoints and scripted provider fixtures: three successive compactions; switch from16000 to8000 configured context; goals/corrections/todos/source paths; persisted raw offload; summary failure preserving the current checkpoint; purpose accounting and suppression of summary reply tokens. Actual native read_file also tests long-file truncation and subsequent pagination to the final row while original checkpoint files remain intact. Seeded complete tool pairs are explicitly synthetic evidence; no host-file/MCP effect is inferred from them.

The browser fixture initially failed because its scripted responder returned tool calls for native summaries. The explicit synthetic FixtureModel now provides a fixture-only text summary and carries its prior fixture tool receipts; no such response is injected into a configured real provider. Inbox boundary testing uses a larger window to isolate delivery semantics; small-window behavior has dedicated tests.

Limitations: no paid/live provider summary-quality or Ubuntu proof; automatic summaries are model output and can still omit semantic detail, while raw evidence remains checkpointed. Child-agent compaction, abrupt power loss and the full recovery matrix are not yet covered by these tests. Very large summary/target responses still need bounded result transport. No new UI pixel comparison is claimed. See the current evidence record in evidence/2026-10-03/native-compaction.json; global AT status is unchanged until full acceptance is proven.
