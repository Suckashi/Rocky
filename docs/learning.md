# Automatic Learning

`off` disables automatic collection. Manual reviewed episodes remain available. `propose` requires explicit owner scope consent, a selected reflection model, a fixed evaluation suite and budgets. Every source Work must separately allow reuse; private/excluded Work and private-memory reads are excluded. Only eligible completed normal Works with observed actions qualify. The default daily bound is three episodes, with at most two candidates per episode, two revisions per candidate and twelve reflection model calls. Automatic work uses Rocky's existing low-priority Work admission, not another agent runtime.

Reflection reads only the reviewed, masked episode and permitted frozen skill revisions. It saves a real immutable candidate package or records `no_learning`. A patch retains the original package files/body and appends a typed reviewed amendment. It must specify steps, verification and episode evidence references. Candidate code, hooks, providers and evaluation assertions are never executed.

候選進入 Learning Inbox，可審查檔案、來源、hash、基底、歷史，編輯後重評、拒絕、撤回或隔離。編輯會產生新 candidate revision，使舊評測與核准失效。發布需要精確 candidate hash、通過的 evaluation ID、仍有效來源以及 base revision／selection 的 CAS；同一基底不能讓兩個競爭候選依序覆蓋。正式 Skills 設定可比較、回滾與隔離固定版本；正常發布只影響下一個工作，security quarantine 會擋下受影響執行的後續工具與載入。

Evaluation suites are owner-authored, versioned data-only JSON. The contract is [learning-evaluation.ts](../packages/contracts/src/learning-evaluation.ts). Supply `id`, `expectedRevision`, `name`, `primaryMetric: "task_success"`, a predeclared `improvement` (`task_success`, `model_calls`, or `tokens`), `minimumImprovement`, `cases`, `modelBudget`, `maxRuns`, `maxModelCalls`, `maxTokens`, `wallBudgetMs` and `reportByteBudget`. Each case has its own UUID/revision, family/source group, split (`train`, `validation`, `holdout`), task prompt, fixture transport, owner approval decision and expected observed writes/native-child result. No JavaScript/YAML hooks, `file://` providers or model-selected graders are accepted.

The trusted Promptfoo worker has no direct network access. Its application-owned provider executes complete Rocky evaluation Works with data-only Node fixture tools, bounded model calls, separate private scratch and a frozen baseline/current/candidate catalog. The comparison fixes model revision, tool/executor policy, case versions and resource budgets in a persisted manifest. Prompts do not choose endpoints. Reports stay local; no cloud sharing or suggestions provider is enabled.

發布 gate 要求至少 6 train／3 validation／3 holdout 個獨立案例、負面不觸發案例、安全與所有 required assertions 通過、validation 不退步且有事先定義的改善、final holdout 無退步，以及真實 candidate 載入紀錄。fixture-only 模型不能證明技能改善；缺資料、未知 usage 或 coding case 沒有安全 executor 都不能通過。final holdout 不提供反思工具讀取；修改候選後，已暴露的 holdout 不能再包裝成未知集合。

Stopping, interruption or changed policy does not replay calls. Explicit retry creates another evaluation while retaining history. Source withdrawal removes corresponding draft/report derivatives and isolates affected published skills; it retains immutable formal history, valid checkpoints and operation evidence. It cannot recall content already sent to a third-party provider. Actual live/model/browser and full failure-matrix validation are recorded separately; implementation is not evidence of a passed gate.

The Inbox accepts the data-only example at `fixtures/eval/learning-suite.json`. It contains 6 training, 3 validation and 3 holdout cases, including rejection and unrelated-task checks. Review applicability before importing: these handwritten synthetic tasks do not establish usefulness for a real repository or business workflow. Choose suitable independent cases before evaluating a particular skill. The import form adds its own request ID; increment `expectedRevision` when replacing a suite. Configured targets repeat each case at least three times and retain all samples. At three variants, the example can require 108 complete Work runs, within its explicit 120-run cap; no model calls occur just by importing it.

Publication includes candidate hash, base revision, evaluation manifest hash and current policy revision. Editing an episode requires review again and invalidates its dependent candidates/evaluations and published skill revisions. The default combined Learning report/cache quota is 1 GiB; set `ROCKY_LEARNING_CACHE_BYTES` before starting the daemon to change it (1 MiB–50 GiB). A full quota stops further calls without deleting formal skills, artifacts or checkpoint evidence. Promptfoo caching and its extra latest-results database are disabled; reports are stored in Rocky. This is an application quota, not an OS filesystem quota.
