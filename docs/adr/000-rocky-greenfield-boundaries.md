# ADR-000: Independent Rocky root

Accepted 2026-10-03. Source specification 2.0.0 is a specification version, not the app version.

Initialize a new Git root in D:/Code/Rocky with no parents imported from other products. Use private npm workspaces and Apache-2.0 for original code. References supply design context only. No code or assets have been copied from Apsis or OpenDots.

Remote creation, visibility, seed push, protection, merge, tag and deployment remain unauthorized and unexecuted. Local commits are permitted by the bootstrap specification.
