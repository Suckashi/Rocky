# Rocky 產品規格（重做版 V1）

> 狀態：草稿，2026-10-05。擁有者已選定：Rocky 當總指揮（A）、全 TypeScript 架構、
> 第一個外部 agent 是 OpenCode、電腦上沒有 Microsoft Office。

## 一句話

Rocky 是只在你電腦上跑的 AI 工程夥伴兼總指揮。你交代事情，它自己做或派給專業的
coding agent，驗證成果後附上收據交給你。

## 目標

1. **交代 → 背景完成 → 驗證過的成果**，附 diff 和收據。
2. **安全邊界清楚**：依 T0–T3 分級核准，結果不明的動作絕不自動重做。
3. **文件是一等公民**：md、html、docx、xlsx、pptx、pdf 都能讀、建立和編輯，中文不會壞。
4. **總指揮**：寫程式的工作可以派給外部 agent，核准統一在 Rocky 處理。
5. **簡單、私密**：一個指令安裝，資料只在本機，沒有遙測。Roko 一直在畫面上。

## 永久不做

雲端部署、區網或遠端存取、多使用者、遙測、行動 App。

## V1 先不做

Rocky 自動決定派給誰、排程例行工作、技能自動學習或演化、OS 沙箱、瀏覽器自動化、
向量 RAG、第二個以後的外部 agent（ACP 這一層寫成通用的，但 V1 只驗收 OpenCode）。

## V1 範圍

| 區塊 | 內容 |
|---|---|
| 對話與工作 | 主對話；可以把事情轉成背景工作；工作列表；工作詳情（時間軸、diff、收據、還原） |
| Rocky 自己的 agent | grep、glob、讀檔、局部編輯（精確字串取代）、建立檔案、跑指令、待辦清單、唯讀子代理；開工時讀專案的 `AGENTS.md`；改完自己跑測試；被拒絕後換個做法 |
| 模型 | OpenAI 相容端點、OpenAI、Anthropic、Ollama；prompt caching；429 和網路錯誤會重試（只在確定請求沒有產生效果時） |
| 外部 agent | 透過 ACP 接 OpenCode；由你指定派給它；它在獨立的 git worktree 裡工作；權限請求轉到 Rocky 核准；做完由 Rocky 驗證並整理收據 |
| 核准 | T0 讀取免問（機密檔擋下）；T1 專案內寫檔、寫記憶：先存快照再自動套用，事後看 diff、可以還原；T2 指令：依規則清單，沒涵蓋的就問；T3 對外效果：每次都問 |
| MCP | 接你自己設定的 server（stdio、http）；依工具分別設定核准 |
| 文件 | 六種格式都能轉成 Markdown 來讀、都能建立新檔；docx、xlsx、pptx 可以在保留格式的前提下編輯；有預覽 |
| 記憶 | 存成 Markdown 檔；中文搜尋可用；寫入有收據、可以撤銷 |
| 技能 | `SKILL.md`，需要時才載入完整內容；由你手動安裝；技能不帶任何權限 |
| 評測 | 本機約 30 個真實任務，一鍵跑分，可以比較不同版本或不同模型 |
| 介面 | 繁體中文；參考 OpenDots 的版面；Roko 隨狀態（閒置、工作中、等你核准、完成、出錯）播放動畫 |

## 成功標準

- 在乾淨的 Windows 上，從安裝到第一次對話不超過 5 分鐘、一個指令。
- 一般寫程式任務，每個工作平均跳出的核准不超過 2 次。
- 未經核准的 T3 動作為 0；自動重做結果不明的動作為 0。兩項都要有自動化測試證明。
- 評測任務集訂出基線，之後每一版都不准退步。
- 六種格式各自有含中文的往返測試（讀 → 改 → 再讀內容不變）。
- OpenCode 委派：在 Windows 原生環境完成一個「修 bug＋跑測試」任務，核准從頭到尾都在 Rocky 處理。

## 已知風險

- **OpenCode 在原生 Windows**：官方建議在 WSL 上用，原生體驗較差。第一週先做驗證；
  如果原生版本不穩，就退回「Rocky 透過 WSL 啟動 OpenCode」。
- **沒有 Office**：xlsx 公式由 Rocky 寫入後，設定成開檔時重算；Rocky 自己的預覽會標示
  「未重算」。轉 PDF 用系統內建的 Edge。需要高擬真轉檔時，引導你選裝 LibreOffice（選配）。
