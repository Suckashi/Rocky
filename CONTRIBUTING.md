# Contributing to Rocky

Use Node 24.12.0 and npm 11.6.4. Run `npm ci`, `npm run check`, `npm test`, and `npm run build`. Use `npm run dev` for local development.

This repository begins on `feat/rocky-foundation`. After explicitly authorized remote bootstrap, use feature branches and reviewed pull requests with Windows and Ubuntu verification. CI configuration is not evidence that CI has run.

Changes reference task, requirement and acceptance IDs from `specs/rocky/implementation-plan.json`. Include actual validation and remaining limits. Product namespaces belong to Rocky; do not add cross-product compatibility or import upstream application trees.
