# Support

Rocky is a development preview maintained through this repository. There is no commercial support service or response-time guarantee. Reports in English or Traditional Chinese are welcome.

Start with the [user guides](docs/README.md), [known gaps](docs/ROADMAP.md), and [development guide](docs/development.md). After GitHub hosting is established, use its Issues tab and choose Bug report, Feature request, or Question. Search existing reports first. For a bug, include the Rocky revision, relevant environment, minimal reproduction, expected behavior, and sanitized output. Use synthetic files or a small public example. Maintainers triage these forms manually; there is no automatic rejection bot.

Run `npm run doctor` for local diagnostics. Review output before sharing: remove keys, headers, model prompts, user content, local account names, and private paths. Do not upload your data directory, browser profile, backup, or `.env` file.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) and use private reporting. For community conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Do not put sensitive details in a public issue.
